# 커스텀 라이어게임 프로젝트 명세

## 핵심 요약

이 프로젝트는 두 가지 플레이 방식을 제공한다.

1. 1기기 모드
   - 닉네임 없이 참가자 수만 입력
   - 한 대의 기기로 순서대로 키워드 확인
   - 토론/투표/결과 공개 없음
   - 모든 참가자 확인 후 카테고리 선택으로 복귀

2. 여러 기기 모드
   - 방장이 방 생성
   - 참가자는 방 코드/비밀번호/닉네임으로 입장
   - 실시간 대기실, 채팅, 카테고리 투표, 키워드 확인, 설명, 토론, 투표, 결과 공개
   - Supabase Realtime 사용

## 반드시 지킬 UX

- 20개 카테고리는 1기기 모드와 여러 기기 모드 모두 `2 × 10` 배열 기준.
- 여러 기기 모드의 카테고리 투표는 10초 자동 종료.
- 카테고리 결정 후 3초 뒤 자동으로 키워드 확인.
- 키워드 설명은 참가자 순서대로 각 30초.
- 현재 설명자만 설명 채팅과 완료 버튼 사용 가능.
- 토론 화면은 채팅과 투표를 동시에 제공.
- 결과 화면에서 스파이모드가 아니면 스파이 항목 숨김.
- 결과 화면에서 라이어 키워드 표시.
